# v0.9.1

## Novedades

- Quick Training guarda presets con nombre que incluyen ambos equipos, el orden de los personajes, las asistencias y el escenario. Los presets se conservan entre sesiones.
- Al iniciar MVC3, el mod comprueba en segundo plano si hay una versión estable más reciente en GitHub. Si la release incluye el instalador oficial, el aviso permite abrir la descarga en el navegador.

## Correcciones

- F5 abre la ventana de herramientas cuando MVC3 o el mod tienen el foco.
- El hook de grabación se instala una sola vez por sesión.

## Instalación

Cierra MVC3 antes de ejecutar `UMVC3TrainingToolsInt-Setup.exe`. Abre **Quick Training** con **F4** desde el menú principal y usa **Save preset** y **Load preset** para guardar y recuperar configuraciones.

## Publicación

- GitHub Actions genera un instalador x64 verificado en las PR a `main` y en las ejecuciones manuales. Al subir una etiqueta de versión, publica la release estable con el instalador y su changelog.
