# v0.9.3

## Actualización del mod

- Al aceptar una actualización en MVC3, el mod descarga el instalador de GitHub y comprueba su SHA-256 antes de cerrar el juego. El instalador aplica la versión a la instalación que se está usando y vuelve a abrir MVC3.
- Si la carpeta está protegida, Windows puede pedir permiso de administrador para instalar. El juego se vuelve a abrir con los permisos de la sesión original.
- Las instalaciones de v0.9.2 y anteriores deben aplicar este instalador una vez para habilitar la actualización completa en futuras releases.
