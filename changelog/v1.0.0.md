# v1.0.0

## Presets de entrenamiento

- Guarda equipos, orden, asistencias, colores y escenario desde Entrenamiento rápido (**F4**). Añade la posición inicial y de reinicio y las reacciones de J2 para guardar un ejercicio completo.
- La pestaña **Preset** de **F5** permite guardar la configuración actual, actualizar o borrar presets y aplicarlos en el combate. Para abrir el escenario guardado, usa **F4** desde el menú principal.
- Los presets de equipo anteriores se pueden seguir cargando.

## Equipos y acceso rápido

- Cada personaje aparece en una fila desplegable con sus ajustes de personaje, asistencia y color. Las flechas permiten reordenar los equipos.
- Elige los colores base y el traje alternativo cuando esté instalado. Los cambios se pueden aplicar durante el entrenamiento desde **Equipos**.
- La recarga comprueba el color o traje aplicado a cada personaje, incluso si cambia de posición en el equipo.
- F4 usa la carga directa cuando detecta que la ruta por los menús del juego no está disponible y la carga directa es compatible.
- Si el juego arranca configurado en pantalla completa, el mod lo abre sin bordes para que F4 y F5 puedan mostrar sus ventanas sin necesitar Timestone.

## Diagnóstico y documentación

- Los registros incluyen la compilación, la hora UTC, el modo de acceso rápido, las operaciones de presets y el resultado de las recargas y reinicios.
- **Archivo → Abrir carpeta de registros** lleva a los archivos necesarios para reportar un fallo. El README documenta las funciones y el proceso de reporte en inglés y español.
